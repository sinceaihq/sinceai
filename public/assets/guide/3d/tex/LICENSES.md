# Texture licences — campus twin

Every texture set in this folder is released under **CC0 1.0 Universal** (public domain dedication).
No attribution is legally required; the guide credits the sources anyway ("Textures: ambientCG, Poly Haven, TextureCan (CC0)").

Files: `<set>/<set>_<1k|2k>_<map>.webp` — `color` (sRGB), `normal` (OpenGL +Y, linear), `rough` (roughness, linear), `ao` (ambient occlusion, linear), `metal` (metalness). Converted from the source PNG/JPG with libwebp (colour q82, normal q90). `tile` = metres covered by one texture repeat (used by `components/guide/twin/engine/render/materials.ts`).

Notes

- `metal_white_painted` reuses the normal and roughness maps of ambientCG Metal029 with a generated white albedo (luminance mottling of the Metal029 colour map).
- `carpet_dark/carpet_dark_1k_color_anthracite.webp` is a desaturated variant of the Carpet012 colour map (anthracite instead of navy).
- `granite_kerb` roughness is remapped to 0.70–0.90 (flamed/sawn granite); the source scan is a polished worktop.
- Sets without an AO map have none at the source (flat, polished or foliage surfaces).
