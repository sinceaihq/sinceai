# Security Policy

Since AI takes the security of [sinceai.ai](https://sinceai.ai) and of the people who use it seriously.
Thank you for helping keep it safe.

## Supported versions

This repository is a continuously deployed website. Only the latest commit on `main` — the version running
at [sinceai.ai](https://sinceai.ai) — receives security fixes.

## Reporting a vulnerability

**Please do not report security issues in public GitHub issues, discussions or pull requests.**

Report privately through either channel:

- **GitHub:** [Report a vulnerability](https://github.com/sinceaihq/sinceai/security/advisories/new)
  (private vulnerability reporting).
- **Email:** [info@sinceai.fi](mailto:info@sinceai.fi) with the subject line `Security report: <short summary>`.

Please include:

- the affected URL, file or component,
- steps to reproduce, or a proof of concept,
- the impact you expect, and
- how you would like to be credited (or that you prefer to stay anonymous).

## What to expect

- We acknowledge your report within **3 business days**.
- We keep you informed while we investigate, and agree a disclosure date with you.
- We aim to fix confirmed critical issues within **14 days**.
- With your permission, we credit you once the fix is live.

## Scope

In scope: the code in this repository and the website it deploys to, **sinceai.ai**.

Out of scope here: **sinceai.app** (report to the same email address and it reaches the right team),
third-party services we link to or embed, denial-of-service and volumetric testing, social engineering,
and findings from automated scanners without a demonstrated impact.

## Safe harbour

We will not pursue legal action against good-faith research that respects this policy: avoid privacy
violations and service disruption, access only the data you need to show the issue, and give us
reasonable time to fix it before any public disclosure.
